# Zoolama

Offline supermarket helper for your phone: a running cart total that survives closing the app,
and a unit-price comparator (R$/kg, R$/L, R$/un) to find the cheaper option.

Runs entirely offline as a PWA — no build step, no dependencies.

## Develop

```sh
npm test                      # unit tests (node --test)
python3 -m http.server 8765   # then open http://localhost:8765
```
